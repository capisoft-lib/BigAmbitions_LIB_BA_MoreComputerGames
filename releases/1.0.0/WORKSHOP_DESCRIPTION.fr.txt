[h1]More Computer Games (MCG) 1.0.0[/h1]
Donnez à votre ordinateur de nouvelles façons de vous distraire de votre empire. MCG est une bibliothèque commune pour les mini-jeux de Big Ambitions.

[h2]Un ordinateur, plusieurs jeux[/h2]
[list]
[*]Ouvrez le catalogue directement sur le moniteur avec l'action native Jouer aux jeux vidéo.
[*]Gardez le casse-briques original et ajoutez séparément des mods de jeux compatibles.
[*]Chargez les ressources de chaque jeu uniquement lorsque vous choisissez d'y jouer.
[*]Conservez les meilleurs scores locaux des jeux vanilla et moddés dans un même système.
[*]Retrouvez l'interface MCG dans les 22 langues sélectionnables du jeu. Les mods de jeux fournissent leurs propres traductions de gameplay.
[*]Revenez au menu des jeux ou quittez l'ordinateur grâce aux boutons sous le moniteur.
[/list]

[h2]Commandes[/h2]
[b]Haut/Bas[/b] : choisir un jeu. [b]Entrée[/b] : jouer.
[b]Retour arrière[/b] : revenir au catalogue ou annuler le chargement.
[b]Tab[/b] : quitter l'ordinateur. [b]Échap[/b] : menu pause natif, inchangé.
Le bouton traduit [b]Retour au menu [Backspace][/b] revient au catalogue ou annule un chargement sans quitter le PC. Il apparaît pendant un jeu, un chargement ou une erreur de lancement, puis disparaît dans le catalogue.
Le bouton natif pour [b]quitter[/b] conserve son texte traduit et affiche [b][TAB][/b] pendant l'utilisation de MCG. Son action ne change pas ; l'indication est retirée à la sortie.
Les raccourcis MCG sont inactifs pendant le menu pause ou les options. Tab respecte le focus de l'interface native.

[h2]Prérequis[/h2]
Cible : Big Ambitions 1.0 Build 3670 sous Windows.
MCG ne nécessite aucune autre bibliothèque de mod. Activez MCG dans la liste des mods.
Redémarrez Big Ambitions après l'installation ou la mise à jour des mods.

[h2]Développeurs : créez votre propre jeu[/h2]
MCG est open source sous licence MIT. Essayez les exemples ou créez votre mini-jeu : MCG fournit les API d'enregistrement, de chargement, de session et de fin de manche pour vous laisser vous concentrer sur le gameplay.

[url=https://github.com/capisoft-lib/BigAmbitions_LIB_BA_MoreComputerGames][b]GitHub — code source, API et exemples MCG[/b][/url]

[url=https://github.com/capisoft-lib/BigAmbitions_LIB_BA_MoreComputerGames/blob/main/docs/CREER_UN_JEU.md]Créer votre premier jeu MCG — guide pas à pas[/url]
[url=https://github.com/capisoft-lib/BigAmbitions_LIB_BA_MoreComputerGames/blob/main/API.md]Référence complète de l'API[/url]

Pour les auteurs : recompiler contre MCG 1.0.0 (assembly 1.0.0.0), déclarer MCG comme dépendance séparée et ne jamais incorporer sa DLL. MCG n'a lui-même aucun Required Item.

[h2]Records locaux et roadmap[/h2]
Seul un meilleur score de manche terminée remplace un record. Les records sont séparés par profil Steam, jeu et règles ; une manche abandonnée ne compte pas. ComputerGameHighScore n'est pas nécessaire.
Nous envisageons d'ajouter prochainement un leaderboard partagé. Il n'est pas encore disponible et aucune date n'est confirmée. Les scores restent locaux, sans envoi en ligne ni compte supplémentaire.

[h2]Validation[/h2]
La compilation et les tests isolés sont documentés dans le dépôt. Les essais en partie réelle et de coexistence restent à réaliser. Les images d'exemple en anglais sont des rendus isolés du moniteur.
